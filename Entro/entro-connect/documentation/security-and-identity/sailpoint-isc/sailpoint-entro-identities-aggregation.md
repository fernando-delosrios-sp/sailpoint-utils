The Entro Security integration with SailPoint IdentityNow enables comprehensive identity lifecycle management and access governance for Non-Human Identities (NHIs) and AI Agents. By exposing Entro data via specialized API endpoints, SailPoint can aggregate these identities, map them to human identities, and apply governance policies.
GitBook Assistant
### Key Capabilities[#key-capabilities](#key-capabilities)

- 

**Account Aggregation**: Automatically pull NHI and AI Agent data from Entro into SailPoint.
GitBook Assistant
- 

**Identity Correlation**: Map `ownerEmail` from Entro NHIs and AI Agents to human identities in SailPoint to establish clear ownership and accountability.
GitBook Assistant
- 

**Access Governance**: View and manage permissions associated with machine accounts within the SailPoint ecosystem.
GitBook Assistant
- 

**AI Agent Monitoring**: Discover and govern agentic AI identities alongside traditional service accounts.
GitBook Assistant

### Architecture[#architecture](#architecture)

This integration uses a "pull" model where SailPoint acts as the client and Entro acts as the data provider.

### Common Issues[#common-issues](#common-issues)

#### 1. Correlation Failures[#id-1.-correlation-failures](#id-1.-correlation-failures)

- 

**Symptom**: NHIs are aggregated but show "Uncorrelated" or no owner.
GitBook Assistant
- 

**Fix**: Verify that the `ownerEmail` field in Entro matches the `email` attribute on the Human Identity in SailPoint exactly.
GitBook Assistant

#### 2. 401 Unauthorized[#id-2.-401-unauthorized](#id-2.-401-unauthorized)

- 

**Symptom**: Aggregation fails with authentication errors.
GitBook Assistant
- 

**Fix**: Regenerate the Entro API Token and update the `Authorization` header in all HTTP Operations. Ensure the token is prefixed with `Bearer` if required by your SailPoint tenant configuration.
GitBook Assistant

#### 3. Paging Issues (Partial Data)[#id-3.-paging-issues-partial-data](#id-3.-paging-issues-partial-data)

- 

**Symptom**: Only a subset of NHIs (e.g., exactly 200 or 1000) are appearing.
GitBook Assistant
- 

**Fix**: Review the **Paging Steps** in the HTTP Operation. Ensure the `$response.nextSkipOffset$` variable is correctly configured in the full URL string.
GitBook Assistant

#### 4. Missing Permissions[#id-4.-missing-permissions](#id-4.-missing-permissions)

- 

**Symptom**: Accounts are aggregated, but the "Permissions" tab is empty.
GitBook Assistant
- 

**Fix**: Ensure "Include permissions in aggregations" is checked in both the Entitlement Management and the Account Schema settings.
GitBook Assistant
