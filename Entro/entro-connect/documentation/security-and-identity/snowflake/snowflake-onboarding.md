#### Register Entro public key[#register-entro-public-key](#register-entro-public-key)

Go back to Snowflake and paste the `ALTER USER` statement to register Entro public key (generated by Entro for this onboarding session).

Activate AccountAdmin roleGitBook AssistantAskCopy
```
USE ROLE ACCOUNTADMIN;
```
Create Entro roleGitBook AssistantAskCopy
```
CREATE ROLE IF NOT EXISTS ENTRO_ROLE;
```
Create Entro userGitBook AssistantAskCopy
```
CREATE USER IF NOT EXISTS ENTRO
PASSWORD = '<EnterPassword>'
DEFAULT_ROLE = ENTRO_ROLE
DEFAULT_WAREHOUSE = <AssignToDefaultActiveWH>
MUST_CHANGE_PASSWORD = FALSE;
```
Grant the Entro role to the Entro userGitBook AssistantAskCopy
```
GRANT ROLE ENTRO_ROLE TO USER ENTRO;
```
Grant the MONITOR privilege at the account levelGitBook AssistantAskCopy
```
GRANT MONITOR ON ACCOUNT TO ROLE ENTRO_ROLE;
```
Grant access to the SNOWFLAKE database where system usage views resideGitBook AssistantAskCopy
```
GRANT IMPORTED PRIVILEGES ON DATABASE SNOWFLAKE TO ROLE ENTRO_ROLE;
```
Grant read-only access to the ACCOUNT_USAGE schemaGitBook AssistantAskCopy
```
GRANT USAGE ON SCHEMA SNOWFLAKE.ACCOUNT_USAGE TO ROLE ENTRO_ROLE;
GRANT SELECT ON ALL VIEWS IN SCHEMA SNOWFLAKE.ACCOUNT_USAGE TO ROLE ENTRO_ROLE;
GRANT SELECT ON FUTURE VIEWS IN SCHEMA SNOWFLAKE.ACCOUNT_USAGE TO ROLE ENTRO_ROLE;
```

GRANT SELECT ON FUTURE VIEWS IN SCHEMA SNOWFLAKE.ORGANIZATION_USAGE TO ROLE ENTRO_ROLE;
