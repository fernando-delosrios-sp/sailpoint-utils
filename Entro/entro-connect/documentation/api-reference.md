### **API URL -> https://api.entro.security**[#api-url-greater-than-https-api.entro.security](#api-url-greater-than-https-api.entro.security)

For dedicated tenants, use the following API URL using the name of you tenant here: `https://<tenant>-api.entro.security `
GitBook Assistant

For example, if tenant URL = https://demo.entro.security, the API url would be https://demo-api.entro.security
GitBook Assistant
### Create API Key[#create-api-key](#create-api-key)

To use the Entro API for administration tasks or for scanning, you must first create an API key with the appropriate scope. 
GitBook Assistant

1. 

Access the [API Keys](https://app.entro.security/admin/settings?tab=api-keys) page under the Settings menu. 
GitBook Assistant
1. 

Click the "Generate new token" button
GitBook Assistant
1. 

Select the appropriate API key type, "Entro API" for all API functions or "CICD scanner API" for use of only the scanning endpoint. 
GitBook Assistant

### Entro API Swagger UI[#entro-api-swagger-ui](#entro-api-swagger-ui)

In the [API Keys](https://app.entro.security/admin/settings?tab=api-keys) page under the Settings menu, click the "[Entro API (Swagger UI)](https://apidocs.entro.security/)" link to view the Swagger page for the Entro API endpoints. 
GitBook Assistant

To access and use the Swagger UI, perform the following steps.
GitBook Assistant

1. 

Enter the [appropriate API URL](/api-reference#api-url-greater-than-https-api.entro.security) and the API key 
GitBook Assistant
1. 

Click the green "Authorize" button, enter your API key again, finally clicking the "Authorize" button 
GitBook Assistant
1. 

Now you may open API endpoints and click the "Try it out" button to test API usage 
GitBook Assistant
