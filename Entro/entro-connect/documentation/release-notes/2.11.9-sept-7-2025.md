**Jira**: The Jira integration has been improved
GitBook Assistant

**Slack Integration**: better Slack archiving and real-time channel description fixes.
GitBook Assistant

**Bitbucket**: The commit author parsing in Bitbucket has been improved.

### Bug Fixes:[#bug-fixes](#bug-fixes)

#### Connector[#connector-2](#connector-2)

- 

**Scanner API**: Fixed issues with line numbers for multiline and base64 secrets, as well as zero-based line numbers.
GitBook Assistant
- 

**SharePoint Docs**: Addressed a bug that prevented the scanning of .docx files.
GitBook Assistant
- 

**ServiceNow**: Fixed an issue where an unused 'parent' field was being sent, and another fix prevents titles from being sent back to the SaaS.
GitBook Assistant
- 

**Account ID**: Ensured that the default account ID is no longer limited.
GitBook Assistant
- 

**Roles Permissions**: Fixed an issue with fetching roles and permissions as part of the grants fallback.
GitBook Assistant
