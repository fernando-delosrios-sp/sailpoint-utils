New Features:
GitBook Assistant

- 

New Deleted Status for Exposed Secrets - New status column for exposed secrets (including generic). Until now, you were not able to see the inventory exposures that were deleted from the exposed locations. Now, with the new column you will be able to see these ex-exposures and filter by them. Note: the validity status won't be changed anymore once an exposed is deleted, and will stay with its latest value.
GitBook Assistant
- 

Scanner API Prevention Logs - A new tab in the Exposed Inventories that will include all the secrets that were found from our scan API logs. The scan API is used for either pre-commit hooks or just like any other API, to trigger our scanner with a code snippet or any other string.
GitBook Assistant
- 

New Authentication Mechanism - Entro moved to a new authentication provider. This will should not affect the current authentication method you have. But will require to set up a new SSO flow with the new provider. The Entro Customer Success team will approach you and assist with setting up the new SSO flow.
GitBook Assistant
