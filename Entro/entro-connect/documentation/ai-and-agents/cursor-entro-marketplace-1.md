## Background[#background](#background)

Developers use Visual Studio Code to move faster. VS Code supports AI-powered workflows through extensions and connected tools, which can trigger actions across external services. That improves productivity, but it can also lead to unreviewed tool calls and accidental secret exposure in prompts or editor content. The SailPoint Visual Studio Code Marketplace provides extensions that add governance for agentic AI workflows, including visibility into tool activity, verifiable audit trails, and secret leakage prevention.
