Recommended: install via the GitHub App install flow for the simplest, most secure setup.

## Configuration Steps[#configuration-steps](#configuration-steps)
1
#### Create a GitHub integration through Entro [#create-a-github-integration-through-entro](#create-a-github-integration-through-entro)

In the Entro Platform, go to **Management → Accounts & Integrations → Add new account → GitHub** and select **GitHub Cloud - New**.
GitBook Assistant2
#### Install GitHub App[#install-github-app](#install-github-app)

Click on **Install on GitHub Organization. **You will be redirected to the GitHub App install page. **Configure** your target organization (or repositories), review permissions, and click **Install** again.
GitBook Assistant3
#### Return to Entro[#return-to-entro](#return-to-entro)

After installation, you will be redirected to Entro. 
GitBook Assistant4
#### Complete onboarding form[#complete-onboarding-form](#complete-onboarding-form)

Fill out the onboarding form in Entro:

**Company Nickname**: Choose or create a name for this organization.
GitBook Assistant

**Worker Group (Connector)**: Select your designated connector agent.
