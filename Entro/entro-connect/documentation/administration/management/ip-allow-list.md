Entro supports configuring an I**P Allowlist** to restrict access to a customer's Entro tenant to trusted IP addresses or IP ranges. This feature is designed to enhance security by ensuring that only approved IPs can interact with your Entro resources.
GitBook Assistant

To set this up, please contact support@entro.security with the request and list of IP addresses to allow.
