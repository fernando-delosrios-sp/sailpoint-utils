## Why

Google Cloud Platform Console-manual Connect currently offers automated mode but stops before mutation because its IAM Typed action names neither the required roles nor executable grant commands. Entro’s pinned Terraform onboarding archive already contains the missing permissions, role identifiers, API lists, and audit-log intent. Distilling those details during skill build makes the Configuration plan complete before an operator starts a run.

## What Changes

**GCP Console-manual action completeness**
- From: one service-account action creates an identity and paraphrases unspecified “read-only roles”; API enablement covers only three host-project services; audit-log setup is absent.
- To: separate service-account creation; a generated, checksummed IAM grant artifact containing Entro’s custom organization role and 12 predefined bindings; generated API enablement following Entro’s Terraform defaults; and an explicit operator-only audit-log Prep step.
- Reason: automated Connect may execute only cataloged, exact mutations.
- Impact: non-breaking for catalog consumers; the GCP plan gains complete steps and evidence.

**Generated artifact alignment**
- Generate the IAM and API artifacts from the pinned Entro GCP Terraform archive.
- Validate that both `entro-connect` skill trees, their checksums, and catalog actions match the generated bytes.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `documentation-ingest`: require the GCP Console-manual row to distill executable Terraform-derived IAM/API actions and the documented operator-only audit-log step into aligned generated skill artifacts.

## Non-goals

- Automating service-account private-key creation or Workload Identity Federation.
- Repairing underspecified AWS or Oracle Cloud Infrastructure actions.
- Reclassifying optional GCP services as Coverages.
- Changing the pinned Entro Terraform source.

## Impact

The change affects `integration_catalog.py`, `catalog_contracts.py`, generated Integration and Skill catalogs, both GCP row folders, ingest tests, and changelog documentation. Connect runtime rules and public APIs remain unchanged.
